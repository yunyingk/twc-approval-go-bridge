## 本次修复

1. 真实记录变更事件的附件对象使用 `attachmentToken`，原解析器只识别 `file_token` / `token`，因此事件漏入队。已补齐真实格式；对象中的 `id` 是单元格标识，不能作为下载 token。
2. Anyreceipt 税率返回十进制文本，飞书数字列拒绝字符串，报 `1254061 NumberFieldConvFail`。台账适配器现按线上字段类型转换明确十进制为 `json.Number`，文本列保持文本；不猜测 `6%` 或 `1,23` 的含义。已有人工事实先保留，再校验待补字段。
3. 此样本同步识别超过原来的 30 秒超时，首条任务因此发生恢复重试；默认请求超时改为 90 秒，保留整体任务的两分钟上限。回写重试复用持久化识别结果。
4. 开启附件识别后继续保留常规事件日志，便于区分连接、事件投递、识别和交付状态。

真实事件与数字列转换均有回归测试；默认和 `no_anthropic` 两种构建的 `go test ./...`、`go vet ./...` 及构建检查通过。
