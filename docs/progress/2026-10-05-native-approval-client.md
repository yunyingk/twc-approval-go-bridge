## 代码边界

新增 `InstanceClient`，使用显式应用身份创建实例、读取实例和模板。调用方必须先持久化 UUID 与来源版本映射；客户端无应用层重发。响应缺少明确协议代码或实例标识时保留为传输/协议失败，不能假定建单未发生。安全错误不含上游消息、表单内容或响应体；冲突可按类型识别。

新增 `DetailFormBinding` 与 `BuildDetailForm`：语义键在配置/调用方提供，模板选择依赖稳定系统 ID 或唯一 `custom_id`，不匹配显示名称或数组位置。必填内容逐行校验，多行输出稳定排序；金额不经过浮点数，币种不猜、联系人不按姓名伪造，附件需审批 file code。条件控件、嵌套明细、未支持控件及丢字段均明确失败。

外部 SDK 和 native form JSON 保留在 `feishu/approval`；没有在该目录塞入来源选择、分组规则、AI 版本判断或财务业务。旧实例接口草稿保留。当前创建请求关闭平台内重提和再次提交，防止绕过未来的本地版本追踪；正式重提由业务状态机另行接入。
