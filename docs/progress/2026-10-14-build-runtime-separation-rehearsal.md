## 关键发现与边界

单平台 save/load 会保留目标平台内容，但导入标签所指向的顶层镜像摘要可从构建端的带证明索引变为平台 manifest。本次构建端为 `sha256:e9eb28e…`，导入端为 `sha256:b3bcd327…`；rootfs 和构建元数据一致。正式发布应记录并验收目标平台 manifest／导入后的镜像引用，不能把构建端索引 ID 直接当作跨主机导入 ID。

本次构建端与接收端使用同一个 WSL Docker Engine，中间真实进行了文件传输、校验、导入和隔离启动；验证的是镜像分发流程，不等于已在第二台服务器或公司生产环境验收。没有验收镜像仓库推送／拉取、异机启动、公司网络或真实 Seal 回调。
